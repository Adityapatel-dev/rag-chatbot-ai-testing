# RAG Customer Support Chatbot AI Testing

## Project Overview

This project is an end-to-end QA/SDET project focused on testing a
Retrieval-Augmented Generation (RAG) based customer support chatbot.

The project covers both traditional software testing and AI/LLM
specific testing.

## Objective

The objective is to build a customer support chatbot that answers
customer questions using information retrieved from a controlled
knowledge base.

The application will then be tested for:

- Functional correctness
- API behavior
- Accuracy
- Relevance
- Groundedness
- Hallucination
- Consistency
- Safety
- Prompt injection
- Robustness

## Technology Stack

- TypeScript
- Node.js
- Playwright
- Promptfoo
- DeepEval
- Postman
- Git
- GitHub
- GitHub Actions

## Testing Approach

The project will combine:

1. Traditional functional testing
2. API testing
3. UI automation
4. Prompt testing
5. LLM evaluation
6. RAG evaluation
7. Security testing
8. Regression testing
9. CI/CD execution
